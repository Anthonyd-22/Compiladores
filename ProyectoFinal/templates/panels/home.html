Panel Administrativo con Flask + Supabase

Este proyecto es una aplicación web administrativa desarrollada con Python (Flask) en el backend y JavaScript + Bootstrap 5 en el frontend. Utiliza Supabase como base de datos relacional en la nube, permitiendo una gestión segura de usuarios y reservaciones.

La interfaz de usuario (UI) y la API están desplegadas como servicios independientes. La API corre en Google App Engine, lo que permite escalabilidad y disponibilidad en la nube, mientras que la interfaz está alojada en otra aplicación Google App Engine.

Tecnologías utilizadas

  • ✅ Flask (API REST con autenticación por token)
  • ✅ Supabase (base de datos PostgreSQL + autenticación)
  • ✅ Google App Engine (deploy de la API y Interfaz de usuario)
  • ✅ Bootstrap 5 (interfaz responsiva)
  • ✅ JavaScript (consumo de la API, manejo de modales y formularios)
  • ✅ HTML y CSS puro (estructura y estilo del sitio)

¿Qué incluye el sistema?

  • 👤 Registro y gestión de usuarios (solo por administradores)
  • 📅 Creación, edición y eliminación de reservaciones
  • 🔐 Control de acceso por roles (admin y usuarios)
  • 🕓 Fechas formateadas y campos validados
  • 🌐 UI y API desplegadas como servicios independientes
  • 📦 API conectada a Supabase con manejo de errores
